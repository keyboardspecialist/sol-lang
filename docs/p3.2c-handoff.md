## Objective

Extend `SolMirRuntimeValues` with one same-ID static
`SolMirRuntimeOwnershipPlan` per recipe and an owned-edge arena. Plans describe
runtime ownership and move/drop semantics, but do not execute them or introduce
a new owner.

P3.2c does not add a physical runtime value, allocator, storage, pointer
encoding, move/drop executor, deep copy, equality execution, host transfer, or
cleanup-edge lowering.

## Approved Design

Ownership-plan classifications are `UNREACHABLE`, `LEAF`, `TEXT`, `PRODUCT`,
`SUM`, `WRAPPER`, `CALLABLE`, and `CAPABILITY`. Owned-edge kinds are `FIELD`,
`BACKING`, `PRIVATE_SOURCE`, and `CAPTURED_RECEIVER`.

- Products describe fields in source order. Sums describe per-variant edge
  slices and semantic tags; execution visits only active-variant fields.
- A wrapper has exactly one transparent `BACKING` edge. A derived capability has
  exactly one `PRIVATE_SOURCE` edge; a root capability has none.
- A callable's `CAPTURED_RECEIVER` edge is producer-specific. Never assign one
  receiver to every function value. Signatures, targets, and root tokens are not
  owned.
- Text owns its header and, if and only if its length is nonzero, one payload.
  Uninhabited recipes have no live values. Initialized logical zero-sized values
  participate in moves but never free objects.
- Plans must not recursively expand recursive recipes.

Moves transfer a root or subtree with zero allocation and make the source
unavailable. A projected move creates an exact hole while siblings remain
available. Exact-hole and covering-ancestor reinitialization retain the existing
MIR behavior. A partly moved aggregate drops only initialized descendants.

The specified drop traversal is deterministic depth-first postorder:

- A product visits active initialized fields in increasing source ordinal, then
  its outer object.
- A sum visits active-variant fields in increasing ordinal, then its outer
  object.
- A wrapper visits its backing only and performs no extra free.
- Text with a positive length visits payload before header.
- A bound callable visits its captured receiver before invalidating its handle.
- A derived capability visits its private source before invalidating its handle.
- A root capability token is never freed; leaves perform no free.

Never visit inactive payloads, holes, padding, tags, borrowed tokens, or moved
roots. Drop is non-fallible, does not refund quota, and adds no failure codes or
sites. P3.3 owns ordering among locals and temporaries, control-flow cleanup
edges, and failure precedence.

## Validation, Metering, And Rendering

Construction is transactional and checks all bytes, work, and scratch. Validation
independently reconstructs the plan and checks raw ranges plus every
cross-arena/predecessor alias relationship before dereferencing. Metering must be
exact. Persistent-arena and validator-scratch fault selection must remain
deterministic. Malformed-owner rendering must write zero bytes.

Canonical buffered rendering declares `ownership-plans=true` and
`move-drop-execution=false`. It emits stable digest-keyed descriptions and must
not expose raw IDs, pointers, capacities, paths, or allocator state.
